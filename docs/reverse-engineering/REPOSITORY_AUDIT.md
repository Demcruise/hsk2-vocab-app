# Repository Audit — Phase 0

Date: 2026-11-11 · Branch audited: `main` @ `2551bbc` · Remote: `github.com/Demcruise/hsk2-vocab-app`

## 1. Summary

The repository contains **two parallel implementations** of the same product ("Kunkwan HSK"):

| Implementation | Location | Stack | Status |
|---|---|---|---|
| PWA (primary, deployed to GitHub Pages) | `index.html` (1.74 MB, 1,849 lines) + `sw.js` + `assets/` | Vanilla HTML/CSS/JS, no build step, no framework | Working; 42/42 smoke checks pass; one confirmed persistence bug (see KNOWN_ISSUES K-01) |
| Native/mobile port | `mobile/` | Flutter 3 / Dart (≥3.4), `shared_preferences`, `flutter_tts`, `speech_to_text`, `audioplayers` | `flutter analyze`: no issues; `flutter test`: 8/8 pass; Android build not possible locally (no Android SDK / JDK) |
| Generated build artifact | `app/` | `flutter build web` output (canvaskit, `main.dart.js`) | Committed build output — not source |

Content covered: **HSK 1 (300 words)** and **HSK 2 (770 words)**, each with 10 generated example sentences, pinyin, English meaning, traditional form, topic tag. HSK 3–9 exist only as unprocessed PDFs in the untracked `all hsk level/` folder.

## 4. Build, deploy, CI

- No build step for the PWA; deployed as static files via GitHub Pages (`.nojekyll`).
- Service worker `sw.js` `VERSION='v18'`, cache `khsk2-v18`; navigation = network-first, assets = cache-first.
- In-app `APP_VERSION='v10'` (independent of SW version).
- **No CI** — no `.github/` directory, no workflows, no lint/format config for JS.
- Tests: `tools/_smoke.js` (Puppeteer-core, hard-coded Chrome path and port 8734, not runnable in CI as-is); `mobile/test/widget_test.dart` (8 tests).
